# Report cover mark

`fast-logo-black.png` is a print-resolution rendering of the official black
FAST logo for light backgrounds.
The [FAST NUCES brand guideline](https://cfd.nu.edu.pk/brand-guideline/) links to
the [university's original black SVG](https://drive.google.com/file/d/1AwvEgcSkfuxadXfEx6rDDOyjEn5GVtWm/view).
The report generator scales the mark proportionally for the cover.
